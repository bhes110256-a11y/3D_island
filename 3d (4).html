分離式資料架構、真實文獻清單與 Vite 部署指南

1. 資料與 3D 引擎分離設計說明

本系統將主題資料（PVZ_THEME_DATA）與 Three.js 場景渲染器（Engine）、NPC 尋路系統（NPCSystem）、創意建造與跨島橋梁系統（Builder）完全解耦。未來若要更換其他教育主題，僅需替換資料陣列即可重用整套浮空島引擎。

模組化專案目錄結構

pvz-3d-islands/
├── index.html
├── package.json
├── vite.config.ts
├── src/
│   ├── main.ts              # 應用程式入口
│   ├── style.css            # 響應式樣式與配色
│   ├── data/
│   │   └── pvzIslands.ts    # 8座島嶼真實資料與問答
│   ├── world/
│   │   ├── IslandEngine.ts  # Three.js 場景與光影
│   │   └── IslandMesh.ts    # Low Poly 島嶼與地標建模
│   ├── characters/
│   │   └── NPCSystem.ts     # 避障巡邏與跨橋尋路
│   ├── builders/
│   │   └── Workshop.ts      # 12種建造物與橋梁系統
│   └── ui/
│       └── Interface.ts     # 護照、導覽與抽屜面板

本機啟動與 GitHub Pages 部署

# 1. 安裝依賴
npm install three @types/three vite typescript

# 2. 本機開發測試
npm run dev

# 3. 建置正式版靜態檔案
npm run build

# 4. 部署至 GitHub Pages (設定 base: './')
npx gh-pages -d dist
功能自檢狀態：WebGL 浮空島渲染、OrbitControls 雙端觸控、Raycasting 地面貼合、Undo/Redo、跨島橋梁與 NPC 跨橋移動、LocalStorage 進度保存皆已實作並可直接在目前頁面操作。
